# Green Tasty — Group Pre-order

Мій проєкт з IT-Марафону EPAM 2026. Взяв наданий застосунок мережі ресторанів (бронювання столиків, меню, pre-order) і реалізував у ньому **Group Pre-order**: власник бронювання збирає замовлення всього столу, а гості додають свої страви за посиланням-запрошенням.

## Що я зробив

- **Group Pre-order для власника:** сторінка групи з гостями та їхніми стравами, шкала готовності, зведене замовлення, відправка в ресторан, видалення гостя, копіювання посилання-запрошення, автооновлення кожні 15 с.
- **Group Pre-order для гостя:** вхід за посиланням `/join/{token}` без реєстрації, свій кошик, підтвердження вибору.
- **Бекенд групи:** сесії гостей, сесія власника, зведення й відправка замовлення, видалення гостя, модульні тести.
- **Кошик:** усі активні столи одним списком, лічильник страв на іконці; пізніше ніж за 30 хв до початку змінити замовлення не можна, завершені бронювання не показуються.
- **Швидке бронювання:** `Book a Table` з картки страви, локації чи меню шукає перший вільний день; страва додається в pre-order одразу після бронювання.
- **Приховування цін для гостей:** перемикач «Hide prices for guests» під час бронювання.
- **Шапка:** закріплена, з міткою «Adding to Table N · дата, час», коли додаєш страви.

## Як перевірити

1. Увійти як `owner.demo@example.com`.
2. **Book a Table** → обрати 2+ гостей і час → підтвердити.
3. **Reservations** → **Group Pre-Order** → **Copy Invite Link**.
4. Відкрити посилання в іншому браузері (інкогніто) → ввести ім'я → додати страви → підтвердити кошик.
5. Повернутися на сторінку групи: гість, його страви й готовність оновилися → **Submit Pre-Order**.

## Що виправив у наданому коді

- Власник рахувався гостем, тому гість не міг приєднатися («Guest limit exceeded»); токен запрошення тепер отримує лише власник.
- Скасовані бронювання блокували слоти часу.
- Пошук вільного дня помилявся на 31-му числі й пропонував дні без вільного часу після 21:15.
- Меню для залогіненого клієнта не додавало страви в кошик.
- Токен власника для гостьових сесій тепер приймається лише з перевіреним підписом Cognito.

## Структура

- `backend/` — .NET 10, Lambda `api-handler` (AWS Syndicate).
- `frontend/` — Angular 22 SPA (S3 + CloudFront).
- `infra/` — Terraform (Cognito, S3, CloudFront, SQS, EventBridge).

## Що не встиг

Адмін-панель (керування столами, стравами, локаціями), сповіщення гостям, приховування цін на рівні API.
